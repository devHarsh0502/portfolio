# Harsh Bhavsar - Portfolio

Full Stack Java Developer portfolio — static HTML with glassmorphism, particle effects, and interactive terminal.

## Features
- Glassmorphism UI with particle background
- Custom cursor with hover effects
- Interactive terminal (press ` or click terminal button)
- Scroll reveal animations
- Responsive design
- Contact form
- Resume download

## Local Preview

Just open `index.html` in your browser.

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → Sign up with GitHub
3. Click "Add New Project" → Import your repo
4. Framework: **Other** | Build command: (empty) | Output directory: `.`
5. Click Deploy
6. Done — your site is live at `your-project.vercel.app`

## Custom Domain

1. In Vercel Dashboard → Project → Settings → Domains
2. Add your domain and update DNS as shown
